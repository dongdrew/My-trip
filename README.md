# 🏝️ 보라카이 가족여행 앱

두 가족(우리 가족 3명 + 처제네 3명)의 보라카이 여행을 관리하는 모바일 웹앱입니다.
설치나 서버 없이 폰 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 오프라인에서도 열립니다.

## 기능
| 탭 | 내용 |
|---|---|
| 🏠 홈 | D-day, 오늘 일정, 예약 현황, 비용 요약, 준비물 체크리스트, 공유, 여행 팁 |
| 🗓️ 일정 | Day별 일정 (4박 5일 예시 일정 포함), 텍스트로 카톡 공유 |
| 🎫 예약 | 항공·숙소·픽업·투어 등 예약번호/상태/금액/바우처 링크 관리 |
| 💰 비용 | 페소·원·달러 지출 기록, 분류별 합계, **두 가족 간 정산** 자동 계산 |
| 📍 장소 | 보라카이 주요 해변·맛집·교통 장소, 지도 미리보기·길찾기 |
| 📸 추억 | 날짜별 사진과 이야기 기록 (사진은 폰에 압축 저장) |

## 가족과 공유하는 법
데이터는 각자의 폰에 저장됩니다.
1. 홈 → **📤 백업 보내기** → 카카오톡 등으로 파일 전송
2. 받은 사람: 홈 → **📥 가져오기** → 파일 선택
3. 두 폰의 내용이 **합쳐집니다** (같은 항목은 더 최근에 고친 쪽이 남음, 삭제도 반영)

## 실행
- 정적 파일뿐이라 GitHub Pages에 올리면 바로 사용 가능 (Settings → Pages → 이 브랜치 / root)
- 로컬 확인: `python3 -m http.server` 후 http://localhost:8000
